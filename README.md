# Food Delivery Data Analysis

## 📌 Project Overview

This project focuses on analyzing food delivery data to understand sales, orders, delivery performance, customer behavior, weather conditions, and delivery routes.

The analysis was performed using SQL, Excel, and Tableau.

## 🎯 Objectives

- Analyze food delivery orders and sales
- Understand delivery time and performance
- Analyze orders based on weather conditions
- Identify popular food items
- Analyze delivery routes
- Understand customer gender distribution
- Create an interactive Tableau dashboard

## 🛠️ Tools Used

- **SQL** – Data analysis and queries
- **Microsoft Excel** – Data cleaning and analysis
- **Tableau** – Data visualization and dashboard creation

## 📊 Project Components

### SQL Analysis
SQL queries were used to analyze:
- Total revenue
- Average delivery time
- Food item performance
- Weather conditions
- Delivery routes
- Customer information
- Order trends

### Excel Analysis
Excel was used for:
- Data preparation
- Data cleaning
- Basic analysis
- Organizing the dataset

### Tableau Dashboard
An interactive Tableau dashboard was created to visualize:
- Delivery Method
- Weather Condition
- Traffic Condition
- Top Food Items
- Route Taken
- Gender Distribution

## 📁 Project Files

- `Food Delivery Dataset` – Dataset used for analysis
- `Food Delivery project document` – Project documentation, sheet names and SQL queries
- `Doc1.docx` – Tableau dashboard screenshot

## 📈 Key Insights

The project provides insights into food delivery patterns, customer behavior, delivery performance, popular food items, and different delivery conditions.
